# 汪汪摩托冒险

在线试玩：https://yjw94ss.github.io/dog-motorbike-3d/

电脑和手机浏览器均可游玩，无需安装。
本地 Three.js 3D 游戏：四位动物车手骑摩托穿越 1500 米森林弯道公路，收集骨头、躲避路障、飞跃木坡。资源均在本目录，运行不依赖网络。

## 启动
双击 `启动游戏.command`（需要 Python 3），或在本目录执行：
```sh
python3 -m http.server 8766 --bind 127.0.0.1
```
浏览器打开 http://127.0.0.1:8766 。请通过本地服务器访问，直接双击 HTML 无法加载 ES 模块。

## 操作
左右方向键 / A D：换道；空格 / 上方向键：跳跃；P / Esc：暂停；Enter：开始或重开。底部按钮支持触屏。
每根骨头 10 分；三次独立碰撞后结束；碰撞后保护 1.5 秒；木坡自动跳跃。跑到终点获胜。最高分保存在当前浏览器。

## 角色与弯道
可选小狗阿汪、橘猫小橘、白兔团团、熊猫滚滚，各有独立耳朵、面部、尾巴、头盔和摩托配色。菜单点击角色立即预览；骑行中点击右上角“换角色”会暂停，换好后点击“继续冒险”，保留本局进度与积分。所选角色自动保存。

赛道包含连续左右弯，摩托沿道路自动转向并倾斜，摄像机跟随，道路标线、骨头、路障、木坡和终点均沿弯道布置。左右键依旧控制换道，顶部提示前方弯向。

## 验证
`node --test *.test.mjs` 检查跳跃避障、碰撞保护、结束状态、暂停、终点与重开、角色切换、弯道车道宽度、路面正面朝向、弯道倾斜与重开资源释放。
